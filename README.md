# Group Photo Reaction Bot

Этот проект представляет собой MVP (Minimum Viable Product) Telegram-бота, предназначенного для автоматической реакции на групповые фотографии в чатах и организации простого голосования. Цель MVP — проверить гипотезу о социальной приемлемости и вовлечённости пользователей в игровую механику, основанную на распознавании лиц.

Бот разработан на Golang с использованием библиотеки `tucnak/telebot` для взаимодействия с Telegram Bot API и `github.com/esimov/pigo` для локального распознавания лиц.

## Основной функционал MVP

- **Детекция групповых фото:** Бот автоматически определяет фотографии, содержащие от 4 до 6 лиц (количество настраивается).
- **Предложение голосования:** При обнаружении подходящего фото бот предлагает создать голосование.
- **Визуальная разметка лиц:** На фотографии отмечаются обнаруженные лица с номерами.
- **Создание голосования:** Если пользователь соглашается, бот создает голосование с inline-кнопками для каждого отмеченного лица. Текст голосования настраивается (по умолчанию "Кто тут у нас самый улыбчивый?").
- **Сбор голосов:** Голоса собираются в течение 5 минут (время настраивается).
- **Публикация результатов:** По истечении времени голосования бот публикует результаты в чате.

## Архитектура

Проект состоит из двух основных компонентов:

1. **Bot** - Telegram бот для обработки сообщений и голосований
2. **Admin** - REST API для просмотра статистики и управления (требует авторизации)

Оба компонента используют общую SQLite базу данных.

## Быстрый старт

### Вариант 1: Docker (рекомендуется)

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/matperez/group-photo-reaction-bot.git
cd group-photo-reaction-bot
```

2. **Создайте файл `.env`:**
```bash
cp .env.example .env
# Отредактируйте .env и укажите свои значения
```

3. **Запустите через Docker Compose:**
```bash
make docker-build
make docker-up
```

Админка будет доступна на http://localhost:8080

### Вариант 2: Локальный запуск

1. **Установите зависимости:**
```bash
make deps
```

2. **Создайте файлы `.env`** в папках `bot/` и `admin/` (см. примеры в `.env.example`)

3. **Соберите бинарники:**
```bash
make build-all
```

4. **Запустите сервисы:**
```bash
# В одном терминале
./bin/bot

# В другом терминале
./bin/admin
```

## Конфигурация

### Бот

Переменные окружения (файл `bot/.env` или переменные окружения):

- `BOT_TOKEN` - токен Telegram бота (обязательно, получить у [@BotFather](https://t.me/BotFather))
- `MIN_FACES` - минимальное количество лиц (по умолчанию: 4)
- `MAX_FACES` - максимальное количество лиц (по умолчанию: 6)
- `VOTING_TEXT` - текст голосования (по умолчанию: "кто тут у нас самый улыбчивый")
- `VOTING_DURATION` - длительность голосования (по умолчанию: 5m)
- `DB_PATH` - путь к БД (по умолчанию: bot.db)

### Админка

Переменные окружения (файл `admin/.env` или переменные окружения):

- `ADMIN_PORT` - порт для HTTP сервера (по умолчанию: 8080)
- `ADMIN_USERNAME` - логин администратора (по умолчанию: admin)
- `ADMIN_PASSWORD` - пароль администратора (обязательно)
- `ADMIN_JWT_SECRET` - секретный ключ для JWT (обязательно)
- `ADMIN_DB_PATH` - путь к БД (по умолчанию: bot.db, должна совпадать с ботом)

## Команды Makefile

### Сборка
- `make build-bot` - собрать бинарник бота в `bin/bot`
- `make build-admin` - собрать бинарник админки в `bin/admin`
- `make build-all` - собрать оба бинарника

### Docker
- `make docker-build` - собрать Docker образы
- `make docker-up` - запустить контейнеры
- `make docker-down` - остановить контейнеры
- `make docker-logs` - показать логи
- `make docker-restart` - перезапустить контейнеры
- `make docker-clean` - остановить и удалить volumes

### Разработка
- `make lint` - запустить линтер для всех проектов
- `make test` - запустить тесты для всех проектов
- `make deps` - установить зависимости
- `make clean` - очистить артефакты сборки

Подробнее см. `make help`

## REST API Админки

Админка предоставляет REST API для просмотра статистики:

- `POST /api/auth/login` - авторизация (логин/пароль → JWT токен)
- `GET /api/sessions` - список сессий голосований
- `GET /api/sessions/:id` - детали сессии
- `GET /api/stats` - общая статистика
- `GET /api/chats` - список чатов
- `GET /api/chats/:id` - детали чата

Все endpoints кроме `/api/auth/login` требуют авторизации через JWT токен в заголовке `Authorization: Bearer <token>`.

## База данных

Проект использует SQLite для хранения данных:
- Сессии голосований
- Голоса пользователей
- Информация о чатах
- Пользователи админки

База данных создается автоматически при первом запуске с применением миграций.

## Требования

- **Go 1.25.5** или выше (для локальной разработки)
- **Docker** и **Docker Compose** (для запуска в контейнерах)
- **Telegram Bot Token** (получить у [@BotFather](https://t.me/BotFather))

**Примечание:** Каскадный классификатор для детекции лиц встроен в бинарник через `embed`, внешние файлы не требуются.
