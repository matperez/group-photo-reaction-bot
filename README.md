# Group Photo Reaction Bot

Telegram-бот для автоматического обнаружения групповых фотографий и создания интерактивных голосований.

## Описание

Бот автоматически анализирует фотографии, отправленные в групповые чаты, определяет количество лиц на них и предлагает создать голосование. Участники чата могут проголосовать за наиболее понравившегося человека на фото, а результаты публикуются автоматически по истечении времени голосования.

## Основные возможности

- 🔍 **Автоматическое обнаружение групповых фото** — бот анализирует все фотографии в чате
- 👥 **Детекция лиц** — определяет количество людей на фото (настраиваемый диапазон: 4-6 человек)
- 🎨 **Визуальная разметка** — автоматически отмечает лица на фото с номерами
- 🗳️ **Интерактивное голосование** — создает голосование с inline-кнопками для каждого участника
- ⏱️ **Таймер голосования** — автоматически завершает голосование через заданное время (по умолчанию 5 минут)
- 📊 **Публикация результатов** — автоматически подсчитывает и публикует результаты

## Быстрый старт

### Требования

- Go 1.25.5 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

**Примечание:** Каскадный классификатор для детекции лиц встроен в бинарник, внешние файлы не требуются.

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/matperez/group-photo-reaction-bot.git
cd group-photo-reaction-bot
```

2. Перейдите в каталог бота и установите зависимости:
```bash
cd bot
make deps
```

3. Создайте файл `.env` в каталоге `bot/`:
```env
BOT_TOKEN=your_bot_token_here
MIN_FACES=4
MAX_FACES=6
VOTING_TEXT=кто тут у нас самый улыбчивый
VOTING_DURATION=5m
```

**Примечание:** Каскадный классификатор встроен в бинарник через `embed`, параметр `CASCADE_PATH` больше не требуется.

5. Запустите бота:
```bash
make run
```

Подробные инструкции по установке и настройке см. в [README бота](bot/README.md).

## Разработка

### Команды Make

Все команды выполняются из каталога `bot/`:

```bash
cd bot

make help          # Показать справку по командам
make lint          # Запустить линтер
make test          # Запустить тесты
make build         # Собрать приложение
make run           # Собрать и запустить
make install-linter # Установить/обновить golangci-lint
```

### Конфигурация

Все параметры настраиваются через переменные окружения:

- `BOT_TOKEN` — токен Telegram бота (обязательно)
- `CASCADE_PATH` — путь к файлу каскадного классификатора
- `MIN_FACES` — минимальное количество лиц (по умолчанию: 4)
- `MAX_FACES` — максимальное количество лиц (по умолчанию: 6)
- `VOTING_TEXT` — текст голосования
- `VOTING_DURATION` — длительность голосования (по умолчанию: 5m)

## Принципы работы

### MVP-подход

Проект реализует минимально жизнеспособный продукт для проверки гипотезы о вовлеченности пользователей. Основные принципы:

- Простота — минимум функций, максимум ценности
- Фокус на метриках — измерение вовлеченности и повторного участия
- Без монетизации — проверка социальной приемлемости, а не бизнес-модели

Подробнее см. [MVP-документ](mvp.md).

### Пользовательский опыт

Бот спроектирован для дружеских чатов и неформальных групп. Он:

- Не спамит — реагирует только на групповые фото с нужным количеством лиц
- Не раздражает — имеет rate limiting (не чаще 1 раза в час на чат)
- Прост в использовании — один клик для создания голосования, один клик для голоса

Подробнее см. [UI-Flow](ui-flow.md).
